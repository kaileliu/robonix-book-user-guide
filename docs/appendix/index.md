# 附录与维护

本部分用于处理“已经在使用之后”的问题：遇到异常时怎么恢复，术语是什么意思，管理员在哪里处理账户和服务，以及如何参与 Robonix 和手册的维护。

## 本章导览

| 内容 | 适合谁 | 入口 |
|---|---|---|
| 问题排查 | 所有使用者 | 按现象检查登录、启动、Client、任务和云端恢复问题 |
| 常用概念 | 第一次接触术语的读者 | 解释 Hub、Console、Client、原语、服务、技能和部署等词 |
| 管理后台 | Hub Cloud 管理员 | 处理用户、反馈、邮件、审计、目录同步、监控和站点设置 |
| 参与维护 | 代码和文档贡献者 | 修改 Robonix 代码、补充手册、运行检查和提交变更 |

普通使用者通常只需要先看[问题排查](../troubleshooting/index.md)和[常用概念](../concepts/glossary.md)；管理员和贡献者再进入对应的专门页面。
