# 连接机器人，完成第一条任务

机器人已在 Console 中启动后，在操作者电脑[安装 Client](client.md#安装-client)。Client 是与机器人对话的窗口；两者可以运行在同一台电脑上。

## 连接机器人

1. 在 Console“概览”的“连接 robonix-client”中复制机器人地址和 Atlas 端口。
2. [启动 Client](client.md#启动并连接)，打开 [http://127.0.0.1:7860](http://127.0.0.1:7860)。
3. 填写 **Robot Host** 和 **Atlas Port**，点击 **Connect**，等状态变为在线。**Liaison Endpoint** 通常留空。

![Client 中填写机器人地址和 Atlas 端口并连接成功](/img/hub/client-connected.png)

*填写地址（1）和端口（2），确认在线状态（3）。使用 Console 显示的实际值，不要照抄截图地址。*

同机使用时，机器人地址可填 `127.0.0.1`。跨电脑连接时，在 Console 按提示“允许其他机器连接”并确认，由 Console 保存为新版本，再重新启动；只在可信网络中开放。Console 的 SSH 隧道只转发管理页面，Client 连接条件见[机器人端准备](client.md#准备机器人端)。

## 发送一次相机任务

发送“目前有哪些能力？”，收到回复后，有相机和图像理解能力的机器人可以继续输入：

> 用头部相机拍一张前方的照片，告诉我看到了什么

换用其他机器人时，使用它实际安装的相机。也可以问“你能看到什么？”。相机和相关软件可在 [Hub 目录](https://hub.robonix.ai/discover)查看。

![Client 中发送头部相机拍照任务并收到结果](/img/hub/client-camera-task.png)

*发送任务后等待最终回复，再对照现场或仿真画面检查结果。*

## 检查任务结果

“已提交”只表示任务已提交。等待最终回复，并查看 **Current Goal** 的完成状态；对照现场或仿真画面检查描述是否相符。

## 调整或结束任务

任务执行中，再点 **Send** 会把新要求加入当前任务。要取消，点红色 **ABORT ALL TASKS**，等界面回到空闲。需要停止整套系统时，再到 Console“概览”点“停止”。

真机移动或抓取前，先确认限速、停止行为、急停和测试区域；Client 取消按钮不能替代硬件急停。
