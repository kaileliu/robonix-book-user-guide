# 在线体验

无需安装，也不需要机器人。打开 [Console 在线演示](https://hub.robonix.ai/demo/local)，先熟悉操作；修改只保存在你的浏览器中。

![Console 概览中的运行按钮、连接信息和当前配置](/img/hub/console-overview.png)

*概览告诉你：当前用哪套配置、是否运行、Client 该连接哪里。截图中的地址是演示数据。*

## 修改并保存配置

1. 打开[配置页](https://hub.robonix.ai/demo/local/deployment)，展开一个条目，修改一项参数。
2. 点“保存为新版本”，填写说明，查看修改前后的差异再保存。

## 检查保存结果

打开[历史页](https://hub.robonix.ai/demo/local/versions)，确认出现刚保存的记录，再选择旧版本点“与当前对比”，查看它与当前清单的差异。

也可以在右侧 **AI 机器人配置助手**中输入“检查当前配置”。让它修改参数时，先阅读确认卡片，再选择“同意”或“拒绝”。

## 选择下一步

打开 [Hub 目录](https://hub.robonix.ai/discover)：在[机器人](https://hub.robonix.ai/discover/robot)中找型号，在[服务包](https://hub.robonix.ai/discover/service)和[技能包](https://hub.robonix.ai/discover/skill)中找功能。

演示里的“运行中”是示例状态。想实际完成任务，继续[运行 TIAGo 仿真](simulation.md)，或[使用自己的机器人](../integration-guide/index.md)。
