# 管理与维护机器人

[Hub](https://hub.robonix.ai/discover)提供目录和云端备份；Console 管理机器人本机的配置与运行。

第一次使用时，先按[安装与连接路线](../integration-guide/index.md)完成 Console 安装、配置与运行，再连接 Client。还没有机器人时，直接从[运行 TIAGo 仿真](../getting-started/simulation.md)开始。

## 运行后的日常管理

| 你要做什么 | 阅读哪里 |
|---|---|
| 保留、切换不同的机器人或实验配置 | [管理多套部署](deployments.md) |
| 查看改动、撤销参数修改 | [配置历史](history.md) |
| 备份到云端、恢复或发给他人 | [备份与分享](cloud.md) |
| 用自然语言检查或修改配置 | [AI 配置助手](assistant.md) |
| 更新程序、调整设置、重新安装 | [更新与维护](maintenance.md) |

要添加功能，从 [Hub 目录](https://hub.robonix.ai/discover)查找，再[修改当前配置](configure.md#添加软件包)。机器人任务见[建图、导航与场景](../tasks/index.md)，异常处理见[问题排查](../troubleshooting/index.md)。

## 对照 Console 页面

| 页面 | 对应操作 |
|---|---|
| 概览 | 选择当前部署、启动停止、取得 Client 连接信息 |
| 配置 | 改参数、加软件包、保存版本 |
| 历史 | 对比、回滚、导入导出 |
| 日志 | 按运行记录查看输出 |
| 更新 | 构建软件包、更新 Console 与 Robonix |
| 设置 | 本机变量、环境脚本、访问设置和部署目录 |

“目录”“我的机器人”“个人主页”“用量”显示 Hub 云端内容；安装和运行操作在目标机器的 Console 中进行。

## 登录后的页面

桌面端左侧分为两组：

- **本机**：概览、部署、版本、日志、更新和设置，管理当前机器人。
- **Hub**：目录、我的机器人、个人主页和用量，查看云端内容。

左侧底部还有账户、反馈和收起侧栏入口。手机端没有左侧栏，顶部提供账户和反馈入口，底部标签栏切换本机、目录、我的机器人和个人主页。右侧的 AI 配置助手用于读取和修改配置，具体操作见[配置助手](assistant.md)。
