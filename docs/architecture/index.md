# 原理与参考

本部分回答三个问题：Robonix 的组件怎样协作，能力怎样被发现和调用，具体接口字段到哪里查。

## 本章导览

| 子目录 | 适合什么时候阅读 | 主要内容 |
|---|---|---|
| 工作原理 | 想知道一次任务在系统中怎样流转 | 组件职责、运行时通信、命名空间、部署启动和多平台关系 |
| 接口目录 | 想知道某个能力能做什么 | 相机、雷达、底盘、建图、导航、Pilot、Executor 等能力的用途和组合方式 |
| 自动生成的参考 | 需要精确填写字段或编写代码 | 能力约定、ROS IDL、Rust 和 Python 接口的原始结构 |

## 推荐阅读顺序

1. 先看[系统组件](components.md)，建立用户、规划、执行、场景和本体之间的整体认识。
2. 再看[运行时通信](runtime-communication.md)，理解能力如何注册、发现和调用。
3. 按需要进入[接口目录](../interface-catalog/index.md)，查某一类硬件、服务或系统能力。
4. 编写软件包或排查字段问题时，使用[自动生成的参考](../reference/index.md)。

参考页描述系统边界和接口结构；具体机器人能否使用某项能力，仍需以 [Hub 机器人目录](https://hub.robonix.ai/discover)中对应整机条目的依赖和 README 为准。
